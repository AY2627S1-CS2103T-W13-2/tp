**ZoomAddress is a desktop participant-management application for directors of large-scale computing events.**
It keeps participant information and assignments to groups, roles, and activities in one local directory. While it
has a GUI, its keyboard-driven command interface lets experienced users work quickly.

* To start using ZoomAddress, see the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* To contribute to ZoomAddress, see the [**Developer Guide**](DeveloperGuide.html).
* To meet the team, see [**About Us**](AboutUs.html).
