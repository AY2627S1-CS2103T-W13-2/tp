# ZoomAddress

[![CI Status](https://github.com/AY2627S1-CS2103T-W13-2/tp/actions/workflows/gradle.yml/badge.svg)](https://github.com/AY2627S1-CS2103T-W13-2/tp/actions/workflows/gradle.yml)

![ZoomAddress interface mockup](docs/images/Ui.png)

ZoomAddress is a desktop participant-management application for directors of large-scale computing events.
It helps event directors keep track of participants and their relevant information, making it easier to coordinate
people across different groups, roles, and activities.

ZoomAddress is optimized for users who prefer fast, keyboard-driven workflows. Its data is stored locally and is
available without an internet connection.

For more information, visit the [ZoomAddress product website](https://ay2627s1-cs2103t-w13-2.github.io/tp/).
